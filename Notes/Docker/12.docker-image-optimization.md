# Docker Image Optimization

## Overview
Image optimization helps reduce build time, image size, and attack surface.

## Key Concepts

### Multi-stage builds
- Use multiple `FROM` stages to build artifacts in one image and copy only the final result.
- This keeps runtime images small and cleaner.

```dockerfile
FROM python:3.11-slim AS builder
WORKDIR /app
COPY . .
RUN pip install --no-cache-dir -r requirements.txt

FROM python:3.11-slim
WORKDIR /app
COPY --from=builder /app /app
CMD ["python", "app.py"]
```

### Smaller base images
- Prefer slim or alpine-based images when appropriate.
- Avoid installing unnecessary packages.

### Build cache optimization
- Place files that change less often earlier in the Dockerfile.
- Use layer caching effectively.

## Useful Commands

```bash
docker build -t myapp:latest .
docker images
docker history myapp:latest
```

## Insights
- Smaller images deploy faster and use less storage.
- Multi-stage builds are one of the best practices in modern Docker workflows.
