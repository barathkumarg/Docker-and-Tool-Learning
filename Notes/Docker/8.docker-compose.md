# Docker Compose

## Overview
Docker Compose is a tool for defining and running multi-container Docker applications using a YAML file (`docker-compose.yml`).

## Basic Example

```yaml
version: '3'
services:
  web:
    build: .
    ports:
      - "5000:5000"
  redis:
    image: redis:alpine
```

## Commands

- `docker-compose up` — Starts the services defined in the compose file.
- `docker-compose down` — Stops and removes containers, networks, and images created by `up`.
- `docker-compose logs` — Shows logs for services.

## Use Cases

- Local development with multiple dependent services (databases, caches).
- Simplifies orchestration for small deployments or testing.
