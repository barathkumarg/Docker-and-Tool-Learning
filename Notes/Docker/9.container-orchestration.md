# Container Orchestration

## Overview
Container orchestration automates deploying, scaling, and managing containerized applications. Kubernetes, Docker Swarm, and Nomad are popular orchestration platforms.

## Kubernetes vs Docker Swarm

- Kubernetes: Feature-rich, declarative, strong ecosystem, steeper learning curve.
- Docker Swarm: Simpler, tightly integrated with Docker, easier setup.

## Basic Concepts

- Cluster: Group of nodes (machines) that run containerized applications.
- Node: A worker machine in Kubernetes.
- Pod: Smallest deployable unit in Kubernetes, can contain one or more containers.
- ReplicaSet/Deployment: Ensures specified number of pod replicas are running.
- Service: Exposes pods to network.

## When to Use Orchestration

- Applications with multiple services that need scaling.
- When high availability and resilience are required.
- For rolling updates and declarative deployments.
