# Docker Registry

## Overview
A Docker registry stores and distributes Docker images. Docker Hub is the default public registry, but you can run private registries using `registry:2` or third-party solutions.

## Running a Local Registry

```sh
docker run -d -p 5000:5000 --name registry registry:2
```

## Pushing Images to Local Registry

```sh
docker tag myapp:latest localhost:5000/myapp:latest
docker push localhost:5000/myapp:latest
```

## Pulling Images from Local Registry

```sh
docker pull localhost:5000/myapp:latest
```

## Securing a Private Registry

- Use TLS certificates and authentication for production registries.
- For testing, you can run an insecure registry on localhost and configure your Docker daemon to allow insecure registries.

## Docker Hub

- Create an account and login using `docker login`.
- Push images using `docker push username/repo:tag`.
