# Docker Registry Workflow

## Overview
A Docker registry is where images are stored and shared.

## Key Concepts

### Tagging images
- Tags identify image versions such as `latest`, `v1`, or `dev`.
- Good tags make rollbacks and deployments easier.

```bash
docker build -t myapp:1.0 .
docker tag myapp:1.0 username/myapp:1.0
```

### Pushing images
- Push images to Docker Hub or a private registry.

```bash
docker push username/myapp:1.0
```

### Pulling images
- Pull images to another machine or environment.

```bash
docker pull username/myapp:1.0
```

## Useful Commands

```bash
docker login
docker tag myapp:latest username/myapp:latest
docker push username/myapp:latest
docker pull username/myapp:latest
```

## Insights
- Registry workflows are essential for CI/CD and team collaboration.
- Tagging is important for version control and deployment safety.
