# Docker Intermediate Practice Roadmap

This folder is your practice workspace for moving from Docker basics to an intermediate level.
Use the concepts already covered in [Notes/Docker](../../Notes/Docker/README.md) as the foundation, then complete the tasks below in this repository.

## Goal
By the end of this roadmap, you should be comfortable with:
- Docker Compose for multi-container applications
- Optimized Dockerfiles and image builds
- Volumes, persistence, and data management
- Networking between containers
- Basic security and troubleshooting
- Simple CI/CD and registry usage

## Recommended Learning Order

1. Compose and multi-service applications
2. Dockerfile optimization and multi-stage builds
3. Volumes and data persistence
4. Container networking and service discovery
5. Container health checks and troubleshooting
6. Security basics and image hygiene
7. Registry workflow and image deployment
8. Development and production Compose patterns
